# Разметка Flash для калибровки

Активный GCC linker script: `STM32F401XX_FLASH.ld`.
STM32F401RCT6: 256 КиБ Flash, 64 КиБ RAM.

| Назначение | Сектора | Начало | Последний адрес | Размер |
|---|---|---|---|---|
| Таблица векторов | 0–1 | 0x08000000 | 0x08007FFF | 32 КиБ |
| Журнал калибровки | 2 | 0x08008000 | 0x0800BFFF | 16 КиБ |
| Код, константы, начальные значения RAM | 3–5 | 0x0800C000 | 0x0803FFFF | 208 КиБ |

В нижней области сейчас находится только `.isr_vector` (404 байта).
Остаток этих 32 КиБ не используется основным кодом. Основной образ имеет
лимит 208 КиБ; не следует считать все оставшиеся физические 240 КиБ одним
непрерывным регионом для кода.

Векторы остаются по адресу аппаратного старта. Reset_Handler размещён в
основном коде, его новый адрес записывается линкером в таблицу векторов.
Перенос VTOR и дополнительный загрузчик для этой разметки не требуются
при обычной загрузке из основной Flash. Startup-код не изменён.

Область CALIB объявлена только в MEMORY, без выходных секций и без
инициализирующих данных. В ELF нет загружаемых байтов для этой области.
Запись и чтение журнала пока не реализованы.

Для будущего драйвера экспортированы абсолютные символы:

```text
__calib_flash_start__ = 0x08008000
__calib_flash_end__   = 0x0800C000
__calib_flash_size__  = 0x00004000
```

Конечные адреса исключающие. Это символы линкера, а не хранящиеся во Flash
переменные; в C используют адрес символа. Размеры регионов проверяются
линкером, дополнительно проверяются адрес векторов и размещение кода/данных.
CMake LINK_DEPENDS обеспечивает перелинковку после изменения скрипта.

## Проверка сборки

После сборки:

```powershell
python tests/check_flash_layout.py build/Debug/IMU_sw_1.elf
python tests/check_flash_layout.py build/Release/IMU_sw_1.elf
```

Скрипт проверяет физические адреса всех PT_LOAD с данными, размещение всех
ALLOC-секций, начальный стек, адрес Reset_Handler, таблицу векторов и
экспортированные символы. Он не подключается к плате.

## Прошивка устройства

Использовать адресный ELF (как в текущем Cortex-Debug) или Intel HEX.
Сплошной BIN, сформированный от 0x08000000, включает заполненный промежуток
между векторами и кодом, в том числе сектор калибровки: для сохранения
калибровки его нельзя записывать как один непрерывный образ.

Linker script исключает данные из образа, но не управляет стиранием Flash
программатором. При появлении сохранённой калибровки отдельно проверить,
что инструмент стирает только сектора прошивки и не выполняет mass erase.
Полное стирание удалит журнал. Сохранность журнала при реальной загрузке
ещё не проверена на плате.

## Хранение в одном секторе

По решению пользователя резервируется один сектор. Записи можно добавлять
в свободное место, проверяя CRC и записывая признак завершения последним.
При заполнении потребуется стереть весь сектор и записать новый комплект.
Резервной Flash-копии во время этого стирания нет: сбой питания может
оставить устройство без действующей калибровки. При отсутствии валидной
записи будущий драйвер должен явно сообщать о необходимости калибровки.
